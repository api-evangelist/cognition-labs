# Cognition

> Cognition is an applied AI lab that builds Devin, the first autonomous software engineer. Devin plans, writes, tests, and ships production code, working inside your existing workflows and tools. Cognition also builds Devin for Terminal (CLI), Devin Desktop (formerly Windsurf), and publishes research on AI coding agents.

Cognition's products help engineering teams delegate real software engineering work — bug fixes, feature development, refactors, code migrations, security remediation, and code review — to autonomous agents.
